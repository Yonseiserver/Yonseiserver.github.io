이용 규칙 및 저장공간 안내

Created on April 14, 2026 , last updated on May 30, 2026

2026   ·   Guide   Storage   Slurm   Support

상경대학 서버는 여러 사용자가 함께 사용하는 공용 자원입니다.
서버를 보다 안정적으로 운영하고 모두가 원활하게 이용할 수 있도록, 저장공간 사용과 작업 제출, 문의 방법에 관한 기본 사항을 안내드립니다.

1. 저장공간 안내

상경대학 서버에서는 /mnt/data1/[username] 경로를 공용 저장공간으로 사용합니다. /mnt/data1은 전체 서버에서 공통으로 연결되어 있으므로, 서버를 옮겨 작업하더라도 동일한 경로로 파일에 접근할 수 있습니다.

반면, User home directory는 로그인 시 기본 작업 위치로 설정되지만, 서버마다 실제 경로가 다를 수 있습니다. 예를 들어 hpc 서버에서는 /data/home/[username], brl0-5, hpc-stat1 서버에서는 /home/[username] 형태로 설정되어 있습니다.

기본 안내

  • /mnt/data1/[username]은 대용량 공용 저장공간으로 연결되어 있으므로, 대용량 데이터, 학습 결과, 압축 파일, 중간 산출물은 가능한 한 이 경로에 저장해 주시기 바랍니다.
  • 여러 서버에서 공통으로 접근해야 하는 작업 파일은 /mnt/data1/[username] 아래에 두는 것이 편리합니다.
  • User home directory에는 설정 파일, 간단한 코드, 소규모 파일 위주로 저장하는 것을 권장합니다.
  • User home directory는 가능하면 50GB 미만으로 유지해 주시기 바랍니다.

VS Code에서 /mnt/data1 폴더 열기

VS Code Remote-SSH 환경에서도 /mnt/data1/[username] 폴더를 열어 사용할 수 있습니다.

  1. VS Code에서 원하는 서버에 Remote-SSH로 접속합니다.
  2. 상단 메뉴에서 File → Open Folder...를 선택합니다.
  3. 아래 경로를 입력합니다.
/mnt/data1/$USER

해당 폴더를 열면 VS Code의 Explorer에서 파일을 확인하고, 새 파일 생성, 수정, 저장을 할 수 있습니다.

참고

현재는 별도의 용량 제한 없이 운영하고 있으나, 일부 사용자가 과도하게 많은 저장공간을 장기간 점유하는 경우에는 안정적인 서버 운영을 위해 향후 사용자별 용량 제한을 적용할 수 있습니다.

2. 서버 이용 및 작업 우선순위 안내

상경대학 서버는 상경대학 구성원이 공동으로 사용하는 계산 자원입니다.

다만 서버 자원은 구축 재원 및 운영 목적에 따라 이용 대상이 다를 수 있습니다.

  • 일부 서버 자원은 특정 학과 구성원에게만 제공될 수 있습니다.
  • 사용자별 접근 가능한 서버와 자원은 계정 발급 시 안내된 범위를 기준으로 합니다.
  • 접근 권한이 없는 서버 또는 자원은 사용할 수 없습니다.

자원 배정 정책은 향후 서버 증설 및 운영 상황에 따라 변경될 수 있습니다.

작업 우선순위

  • 상경대학 서버의 작업 실행 순서는 Slurm이 자동으로 결정합니다.
  • 작업은 단순 제출 순서만으로 실행되지 않으며, 대기 시간, 요청 자원 규모, 현재 사용 가능한 자원, 계정 및 서버 설정 등을 종합하여 우선순위가 정해집니다.
  • 여러 개의 GPU나 많은 CPU·메모리를 요청하는 작업은 상대적으로 더 오래 대기할 수 있습니다.
  • 반면 오래 대기한 작업은 시간이 지날수록 우선순위에 반영되므로, 작은 작업만 계속 먼저 실행되도록 고정되지는 않습니다.
  • 일부 계정은 특정 서버군에 대해 상대적으로 높은 우선순위를 가질 수 있습니다.
  • 다만 실제 실행 시점은 서버 사용량과 요청 자원 상황에 따라 달라질 수 있습니다.
  • 필요한 자원을 적절히 지정하여 작업을 제출해 주시면 됩니다.

3. 문의 방법 안내

  • 서버 관련 문의는 Slack의 help 채널에 남겨 주시기 바랍니다.
  • 조교 개인 DM보다 help 채널에 문의해 주시면 여러 조교가 내용을 함께 확인하기 쉽습니다.
  • 여러 사용자가 공통으로 겪는 문제도 채널에서 함께 확인할 수 있어 대응이 더 수월합니다.
  • 개인정보가 포함된 문의는 help 채널에 간단히 남겨 주시면, 필요한 경우 조교가 개인적으로 연락드릴 수 있습니다.
  • 문의 시에는 서버 이름, 실행 명령어, 에러 메시지, 로그 파일 등 가능한 한 구체적인 정보를 함께 남겨 주시기 바랍니다.
