## 1. 저장공간 안내
학과 서버에서는 `/mnt/data1/[username]` 경로를 공용 저장공간으로 사용합니다.
`/mnt/data1`은 전체 서버에서 공통으로 연결되어 있으므로, 서버를 옮겨 작업하더라도 동일한 경로로 파일에 접근할 수 있습니다.

반면, 개인 home 디렉토리는 로그인 시 기본 작업 위치로 설정되지만, 서버마다 실제 경로가 다를 수 있습니다.
예를 들어 hpc 서버에서는 `/data/home/[username]`, brl0-5, hpc-stat1 서버에서는 `/home/[username]` 형태로 설정되어 있습니다.

### 기본 안내

- `/mnt/data1/[username]`은 대용량 공용 저장공간으로 연결되어 있으므로, 대용량 데이터, 학습 결과, 압축 파일, 중간 산출물은 가능한 한 이 경로에 저장해 주시기 바랍니다.
- 여러 서버에서 공통으로 접근해야 하는 작업 파일은 `/mnt/data1/[username]` 아래에 두는 것이 편리합니다.
- home 디렉토리에는 설정 파일, 간단한 코드, 소규모 파일 위주로 저장하는 것을 권장합니다.
- home 디렉토리는 가능하면 50GB 미만으로 유지해 주시기 바랍니다.

### VS Code에서 `/mnt/data1` 폴더 열기

VS Code Remote-SSH 환경에서도 `/mnt/data1/[username]` 폴더를 열어 사용할 수 있습니다.

1. VS Code에서 원하는 서버에 Remote-SSH로 접속합니다.
2. 상단 메뉴에서 `File` → `Open Folder...`를 선택합니다.
3. 아래 경로를 입력합니다.

```bash
/mnt/data1/$USER
```
해당 폴더를 열면 VS Code의 Explorer에서 파일을 확인하고, 새 파일 생성, 수정, 저장을 할 수 있습니다.

### 참고
현재는 별도의 용량 제한 없이 운영하고 있으나, 일부 사용자가 과도하게 많은 저장공간을 장기간 점유하는 경우에는 안정적인 서버 운영을 위해 향후 사용자별 용량 제한을 적용할 수 있습니다.

## 2. 작업 우선순위 안내

- 학과 서버의 작업 실행 순서는 Slurm이 자동으로 결정합니다.
- 작업은 단순 제출 순서만으로 실행되지 않으며, 대기 시간, 요청 자원 규모, 현재 사용 가능한 자원, 계정 및 서버 설정 등을 종합하여 우선순위가 정해집니다.
- 여러 개의 GPU나 많은 CPU·메모리를 요청하는 작업은 상대적으로 더 오래 대기할 수 있습니다.
- 반면 오래 대기한 작업은 시간이 지날수록 우선순위에 반영되므로, 작은 작업만 계속 먼저 실행되도록 고정되지는 않습니다.
- 일부 brl 계정은 brl 서버군에 대해 상대적으로 높은 우선순위를 가집니다.
- 다만 실제 실행 시점은 서버 사용량과 요청 자원 상황에 따라 달라질 수 있습니다.
- 사용자께서 별도로 설정을 변경하실 필요는 없으며, 필요한 자원을 적절히 지정하여 작업을 제출해 주시면 됩니다.

## 3. 문의 방법 안내
- 서버 관련 문의는 Slack의 help 채널에 남겨 주시기 바랍니다.
- 개인 DM보다는 help 채널을 통해 문의해 주셔야 조교들이 내용을 함께 확인하고 대응하기 쉽습니다.
- 공통으로 발생하는 문제도 채널에서 함께 확인할 수 있어 보다 효율적으로 대응할 수 있습니다.
- 개인정보가 포함된 문의는 help 채널에 간단히 남겨 주시면, 필요한 경우 조교가 개인적으로 연락드릴 수 있습니다.
- 문의 시에는 서버 이름, 실행 명령어, 에러 메시지, 로그 파일 등 가능한 한 구체적인 정보를 함께 남겨 주시기 바랍니다.
